# Default community files

GitHub uses the files in this repository for any `dao-wolf` repository that has none of its own.

| File | What it does |
|---|---|
| `pull_request_template.md` | The starting text for new pull requests: a description of about 250 words, one picture where it helps (or "No diagram: reason"), and collapsed review sections. |
| `CONTRIBUTING.md` | Issues welcome, pull requests by invitation, security problems reported privately. |
| `SECURITY.md` | How to report a security problem privately, for any repository without its own policy. |

A repository's own copy of any of these files takes precedence over the default here.
