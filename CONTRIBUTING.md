# Contributing

Thanks for your interest.

- **Issues are welcome.** Open one to report a bug or suggest an idea.
- **Pull requests are by invitation.** Only collaborators can open them. If you'd like to change something, open an issue first.
- **Report security problems privately.** Follow the [security policy](https://github.com/dao-wolf/.github/blob/main/SECURITY.md) instead of opening an issue.

A repository with its own contributing guide follows that guide instead.
